# KSPPER PARCHÍS

Juego web multijugador experimental con códigos privados de sala para 2–4 teléfonos. Ejecutar `npm install` y `npm start`. Para jugar entre teléfonos, desplegar como **Web Service** Node.js con WebSockets (por ejemplo, Render), comando de inicio `npm start`. No usar GitHub Pages: no ejecuta el servidor.

Reglas simplificadas de Ludo, no parchís oficial. Las salas están en memoria y no sobreviven a reinicios; no existe reconexión automática. No se ha desplegado ni probado entre teléfonos todavía.
